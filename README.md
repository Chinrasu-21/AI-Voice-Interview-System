# 🎙️ AI Voice Interview System

An AI-powered voice interview platform that automates candidate screening through outbound voice calls. The system conducts AI-driven conversations, converts speech to text, and provides interview analytics for recruiters.

---

## 🚀 Features

- 🤖 AI-powered voice interview automation
- 📞 Outbound voice calling using Twilio Voice API
- 🎤 Real-time Speech-to-Text using Faster Whisper
- 📄 Automatic interview transcript generation
- 📊 Candidate analytics dashboard
- 📥 Downloadable interview reports
- 🔐 Secure REST API integration
- 💻 Responsive web interface

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Chinrasu-21/AI-Voice-Interview-System.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
.\venv\Scripts\Activate.ps1; uvicorn app.main:app --reload
```
